One line of software error copy that tells the user the brutal truth about what went wrong — and makes them laugh on the way. Entry for the make.fun bounty "Say What Actually Broke".

> We lost your draft because the tab crashed taking 47 other tabs with it. Your work is gone, but your tabs are finally closed.

## Run it

```sh
npx tsx main.ts
cat /output/entry.txt
```

Requires Node 22. The program writes a single fixed line (125 characters) to `/output/entry.txt`, deterministically — no randomness, no clock, no network.
